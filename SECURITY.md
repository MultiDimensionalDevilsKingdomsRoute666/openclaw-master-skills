# Security policy

Please report vulnerabilities in this repository privately, using GitHub private vulnerability reporting on this repository's Security tab. Do not open public issues for vulnerabilities.

This repository is a fork of [LeoYeAI/agent-master-skills](https://github.com/LeoYeAI/agent-master-skills). If a report concerns an upstream skill rather than a change made in this fork, please also report it to upstream so the original project can fix it.
